# QAYTU — Landing storefront (demo)

Casa peruana ficticia de prendas trazables desde la madeja. Landing diseñado como un **sobre de patrón de costura abierto**: la prenda es la vista A, B o C, y la hoja de instrucciones es su trazabilidad (fibra, tinte, comunidad, horas, piezas).

Hecho como pieza de portafolio por **Daniel Yataco** para postular a roles de front-end y full-stack.

## Lo que demuestra

- Dirección de arte comprometida: tipografía propia, grilla de papel reglado, chalk red para la decisión activa, flechas de hilo, piezas numeradas.
- Interacción real: selector de talla que marca todas las piezas, catálogo con filtros, bolso con persistencia local, formulario de drop, A/B test del hero, contador de visitas.
- Supabase opcional (REST + anon key con RLS insert-only) para `leads`, `events` y `ab_hero`.
- Checkout **desactivado a propósito**: esto es portafolio, no comercio real.
- Accesible: WCAG 2.2 AA, teclado, `prefers-reduced-motion`.

## Correr local

```bash
# No necesita bundler. Sirve con cualquier server estático:
python3 -m http.server 5173
# o
npx serve .
```

Abre `http://localhost:5173`.

## Despliegue

Vercel Hobby, sitio estático. `vercel.json` define cache de assets y clean URLs.

```bash
npx vercel --prod
```

## Supabase (opcional)

Si quieres leads reales:

```sql
create table leads (id bigint generated by default as identity primary key,
  email text not null, source text, created_at timestamptz default now());
create table events (id bigint generated by default as identity primary key,
  name text not null, data jsonb, created_at timestamptz default now());
create table ab_hero (id bigint generated by default as identity primary key,
  variant text, action text, created_at timestamptz default now());

alter table leads enable row level security;
alter table events enable row level security;
alter table ab_hero enable row level security;

create policy "ins" on leads for insert to anon with check (true);
create policy "ins" on events for insert to anon with check (true);
create policy "ins" on ab_hero for insert to anon with check (true);
```

Luego inyecta las claves en `index.html` antes del script module:

```html
<script>window.__QAYTU__ = { SUPABASE_URL: "https://xxxx.supabase.co", SUPABASE_ANON: "ey..." };</script>
```
